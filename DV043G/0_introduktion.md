# 0. Introduktion

## 0.1 Algoritmernas roll

En algoritm är en uppsättning av steg som definierar hur en uppgift utförs.

Innan en maskin, som en dator, kan utföra en uppgift måste en algoritm för att utföra den uppgiften definierats och representerats i en form som är kompatibel med maskinen.

När en algoritm för att utföra en uppgift har definierats så kräver utförandet av den uppgiften inte längre en förståelse för de principer som algoritmen bygger på.
Den intelligens (förståelse) som krävs för att lösa ett specifikt problem på sätt och vis finns kodad i själva algoritmen. Det innebär att maskinen som utför stegen inte behöver besitta den ursprungliga intelligensen (förståelsen); maskinen behöver bara kunna exekvera stegen som algoritmen föreskriver.

Detta hänger nära samman med begreppet **abstraktion**, vilket innebär att man döljer komplexa detaljer för att kunna fokusera på en högre nivå. Genom att använda en algoritm kan man fokusera på vad som görs (resultatet) snarare än att behöva förstå varje detalj i hur det går till eller de underliggande teorierna.

Sammanfattningsvis betyder det att när vi väl har "knäckt nöten" och skapat en fungerande algoritm, kan arbetet utföras mekaniskt utan att utföraren (maskinen) behöver ha samma expertis som den som skapade algoritmen.
Som konsekvens begränsas den intelligens som maskiner uppvisar av den intelligens som kan förmedlas genom algoritmer. **Med andra ord så kan en dator lösa ett problem om och endast om det finns en algoritm för att lösa det.** Detta leder till skillnaden mellan:

- Beräkningsbara problem - problem för vilka algoritmer finns
- Icke-beräkningsbara problem - problem för vilka ingen algoritm kan existera

---

- En representation av en algoritm kallas ett program
- För människors bekvämlighet skrivs datorprogram vanligtvis ut på papper eller visas på datorskärmar
- För maskiners bekvämlighet kodas program på ett sätt som är kompatibelt med maskinens teknik
- Processen att utveckla ett program, koda det i maskinkompatibelt format, och mata in det i en maskin kallas programmering, eller kodning
- Program, och de algoritmer de presenterar, kallas kollektivt för mjukvara, i kontrast till maskineriet självt, som kallas hårdvara

## 0.4 De övergripande temana inom datavetenskap

Inom datavetenskapen finns det sju stora idéer som fungerar som övergripande teman för ämnet. Dessa är:

1. Algoritmer: Detta är kärnan i datavetenskapen, och handlar om de stegvisa instruktioner som definierar hur en uppgift utförs. Centrala frågor rör bland annat vilka problem som kan lösas algoritmiskt, hur algoritmer kan analyseras och jämföras, samt hur de kan användas för att skapa intelligent beteende
2. Abstraktion: Detta syftar på konsten att hantera komplexitet genom att dölja onödiga detaljer och fokusera på vad en entitet gör snarare än hur den gör det. Det handlar om skillnaden mellan yttre egenskaper och inre sammansättning
3. Kreativitet
4. Data: Datorer kan representera information som digitaliserats, och algoritmer används för att bearbeta denna data för att hitta mönster, skapa simuleringar och generera ny kunskap. Temat innefattar även hur data lagras, hur fel förhindras och konsekvenserna av det växande digitala universumet
5. Programmering: Detta är processen att översätta mänskliga avsikter till körbara algoritmer. Genom programmeringsspråk skapas abstraktioner som gör det möjligt för människor att lösa mycket komplexa problem trots att hårdvaran i grunden bara utföra enkla steg
