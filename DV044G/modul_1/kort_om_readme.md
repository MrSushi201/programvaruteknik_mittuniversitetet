# Kort om README

En README.md placeras i projektets rotkatalog och fungerar som den primära ingångspunkten för både användare och utvecklare. Filen skrivs i klartext med Markdown-formatering.

---

## Viktiga selektioner i en README.md

### Inledning och syfte

- Ge en kort översikt på några rader om vad projektet eller biblioteket gör, utan att anta att läsaren redan känner till det
- Detta fungerar som projektets snabba presentation ("30-second pitch")
- Innehåller ofta länk till projektets källkod samt grundläggande information om skapare eller licens

### Installation

- Tydliga instruktioner för hur projektet laddas ned och sätts upp
- Kan ofta sammanfattas till korta terminalkommandon (till exempel pip install module eller python setup.py install)

### Användning

- Visa ett eller två förenklade exempel på hur koden körs i praktiken
- Kan täcka steg-för-steg-instruktioner för att sätta igång en fungerande prototyp

### Kompletterande avsnitt

- TODO, lista över planerad utveckling för koden
- CHANGELOG, en översikt över ändringar i de senaste versionerna
- Bidrag och utveckling, riktlinjer och kodkonventioner för utvecklare som vill bidra till projektet
